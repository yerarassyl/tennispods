# TennisPods Workout Records

В эту директорию автоматически выгружаются CSV-файлы тренировок из приложения на iPhone.

### Формат данных:
Каждая строка содержит полный набор 18 показателей CoreMotion на частоте 60 Гц:
* `timestamp` — UNIX-время (секунды)
* `elapsed_sec` — время от старта тренировки
* `qw, qx, qy, qz` — кватернион ориентации ракетки в пространстве
* `roll_rad, pitch_rad, yaw_rad` — углы Эйлера (в радианах)
* `rot_x_rad_s, rot_y_rad_s, rot_z_rad_s` — 3D вектор угловой скорости гироскопа $\vec{\omega}$
* `user_accel_x, user_accel_y, user_accel_z` — линейное ускорение ракетки (без силы тяжести, ускорение ударов и замахов)
* `gravity_x, gravity_y, gravity_z` — вектор силы тяжести $g$ (наклон относительно центра Земли)
