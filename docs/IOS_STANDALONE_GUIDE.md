# TennisPods — iOS Standalone 3D Racket Motion Tracking

Полностью нативное приложение на **Swift 5.9+**, **SwiftUI** и **SceneKit** для трекинга пространственной ориентации теннисной ракетки в реальном времени с помощью встроенного 6-осевого IMU в **Apple AirPods (Pro / Max / 3rd gen)**.

---

## Архитектура проекта

```
TennisPods/
├── TennisPodsApp.swift      # Точка входа SwiftUI App
├── MotionManager.swift      # CoreMotion CMHeadphoneMotionManager, тарирование, SIMD математика
├── RacquetModelNode.swift   # Процедурная 3D-модель ракетки (SceneKit SCNNode)
├── ContentView.swift        # SwiftUI экран с SceneKit оверлеем и телеметрией
└── Info.plist               # Разрешения NSMotionUsageDescription и Bluetooth
```

## 1. Математика преобразования кватернионов (CoreMotion → SceneKit)

### Системы координат:
1. **CoreMotion (AirPods):**
   - Наушник закреплен на шее ракетки. В зависимости от ориентации вкладыша/ножки, его естественные оси могут быть ориентированы иначе, чем у классической ракетки.
   - Reference frame CoreMotion вычисляет кватернион $q_{raw}$ относительно исходного положения при старте отслеживания.
2. **SceneKit (3D сцена):**
   - Правая система координат:
     - $+X$: вправо (ширина ракетки).
     - $+Y$: вверх (продольная ось от ручки к ободу).
     - $+Z$: к камере/наблюдателю (нормаль струнной плоскости).

### Формула калибровки (Zeroing / Tare):
Игрок удерживает ракетку вертикально (обод смотрит строго вверх, струнная плоскость направлена перпендикулярно экрану в сторону пользователя). В этот момент фиксируется опорный кватернион $q_{ref}$.

Относительное вращение вычисляется через умножение Гамильтона на обратный кватернион:
$$q_{rel} = q_{ref}^{-1} \cdot q_{current}$$
где для единичного кватерниона $q^{-1} = q^* = [w, -x, -y, -z]$.

### Согласование базисов:
Для идеальной вертикальной начальной посадки применяется корректирующее вращение базиса $q_{fix}$:
$$q_{scenekit} = q_{rel} \cdot q_{fix}$$

## 2. Настройка Info.plist

Для работы `CMHeadphoneMotionManager` в `Info.plist` добавлены обязательные ключи конфиденциальности:

```xml
<!-- Разрешение на доступ к датчикам движения CoreMotion -->
<key>NSMotionUsageDescription</key>
<string>Приложению требуется доступ к датчикам движения AirPods для отслеживания ориентации ракетки в реальном времени.</string>

<!-- Разрешения Bluetooth для коммуникации с наушниками -->
<key>NSBluetoothAlwaysUsageDescription</key>
<string>Требуется Bluetooth для обмена данными телеметрии с AirPods.</string>
<key>NSBluetoothPeripheralUsageDescription</key>
<string>Требуется Bluetooth для обмена данными телеметрии с AirPods.</string>
```

## 3. Инструкция по сборке и запуску в Xcode

1. Откройте **Xcode** и создайте новый проект **iOS App (SwiftUI)** с названием `TennisPods`.
2. Скопируйте файлы из каталога `ios_app/TennisPods/` в ваш проект.
3. В настройках таргета в разделе **Signing & Capabilities** выберите ваш Apple Developer аккаунт.
4. Включите Bluetooth на iPhone, наденьте/подключите AirPods (Pro 1/2, Max или AirPods 3) к iPhone.
5. Закрепите наушник по центру шейки ракетки с помощью эластичного фиксатора или клипсы.
6. Запустите приложение на физическом iPhone.
7. Нажмите кнопку **«Калибровка (3 сек)»**, удерживая ракетку вертикально струнами к экрану.
