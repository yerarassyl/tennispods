# Пошаговая инструкция: Сборка IPA через GitHub Actions и установка через Sideloadly (Windows)

Эта инструкция позволяет собрать нативное Swift-приложение и установить его на физический iPhone **без Mac** и **без платного аккаунта Apple Developer**.

---

## Этап 1: Бесплатная облачная сборка IPA на GitHub

В проект уже добавлен конфигуратор **`project.yml`** (XcodeGen) и рабочий процесс CI **`.github/workflows/build_ipa.yml`**, который собирает приложение на виртуальном Mac Apple Silicon в облаке GitHub.

### Что нужно сделать:
1. Зайдите на [github.com](https://github.com) под своим аккаунтом и создайте новый репозиторий (например, с именем `tennispods`).
   * Сделайте репозиторий **Private** (или Public по желанию).
2. Привяжите локальную папку проекта к вашему GitHub репозиторию и отправьте код:
   *(Выполните в терминале PowerShell в папке `G:\tennispods`:)*
   ```powershell
   git remote add origin https://github.com/ВАШ_ЛОГИН/tennispods.git
   git branch -M main
   git push -u origin main
   ```
3. Перейдите во вкладку **Actions** в вашем репозитории на GitHub:
   * Вы увидите автоматический запуск процесса **"Build iOS IPA"**.
   * Облачный сервер macOS установит XcodeGen, соберет проект на Swift 5.9 и упакует его в `TennisPods.ipa` (занимает около 1–2 минут).
4. Когда сборка завершится зеленой галочкой, нажмите на этот запуск:
   * В самом низу страницы в блоке **Artifacts** появится архив **`TennisPods-IPA`**.
   * Скачайте его и распакуйте — внутри будет готовый файл **`TennisPods.ipa`**.

---

## Этап 2: Подписание и установка на iPhone через Sideloadly (на Windows)

Утилита **Sideloadly** использует официальный бесплатный механизм Personal Team от Apple. Она автоматически подписывает `.ipa` вашим личным Apple ID и устанавливает его на телефон.

1. **Скачайте и установите необходимые программы на Windows:**
   * **[iTunes для Windows](https://www.apple.com/itunes/)** (важно: **не** из Microsoft Store, а стандартный Win32 установщик от Apple).
   * **[iCloud для Windows](https://updates.cdn-apple.com/2020/windows/001-39935-20200911-1A70AA56-F448-11EA-8109-81483383FAD1/iCloudSetup.exe)** (также стандартная версия).
   * **[Sideloadly](https://sideloadly.io/)** (официальный сайт).
2. **Подготовка iPhone:**
   * Подключите iPhone к компьютеру кабелем USB / Type-C.
   * Если iPhone спросит *«Доверять этому компьютеру?»* — нажмите **Доверять** и введите пароль разблокировки.
3. **Установка приложения:**
   * Запустите **Sideloadly**.
   * В поле **Device** выберите ваш подключенный iPhone.
   * В поле **Apple account** введите ваш личный Apple ID (почту от iCloud).
   * Перетащите файл **`TennisPods.ipa`** в левое окно Sideloadly (иконка IPA).
   * Нажмите большую кнопку **Start**.
   * При первом запуске появится окно ввода пароля от Apple ID (и двухфакторного кода подтверждения с экрана телефона) — это необходимо для получения бесплатного сертификата разработчика у серверов Apple.
   * Дождитесь статуса `Done. Complete!`.

---

## Этап 3: Первый запуск на iPhone

После того как иконка **TennisPods** появится на рабочем столе iPhone:
1. Зайдите в **Настройки** $\to$ **Основные** $\to$ **VPN и управление устройством** (или *Профиль и управление устройством*).
2. В блоке *ПО разработчика* нажмите на ваш Apple ID и выберите **«Доверять»**.
3. **Для iOS 16 и новее:**
   * Зайдите в **Настройки** $\to$ **Конфиденциальность и безопасность**.
   * Пролистайте в самый низ до пункта **«Режим разработчика» (Developer Mode)**.
   * Включите его и перезагрузите телефон по запросу системы.

---

## Этап 4: Запуск и калибровка ракетки

1. Наденьте или подключите AirPods к телефону через Bluetooth.
2. Закрепите один наушник по центру шейки ракетки (в вилке) с помощью эластичного фиксатора или стяжки.
3. Откройте приложение **TennisPods**. Индикатор статуса вверху загорится зеленым: **«AirPods Подключены»**.
4. Удерживая ракетку вертикально (ободом строго вверх, струнами к экрану iPhone), нажмите кнопку **«Калибровка (3 сек)»**.
5. На экране начнется обратный отсчет: `3... 2... 1...`.
6. После калибровки вращайте ракетку — 3D-модель на экране будет в точности повторять каждое ваше движение в реальном времени!
